# Bruno collection

Requests for every PDFQ endpoint, with assertions, so the collection doubles as a smoke test.

Start a server with the example templates mounted:

```sh
docker run --rm -p 3000:3000 -v "$PWD/examples:/templates:ro" ghcr.io/nseaseb/pdfq:0.1.0-typst0.15.1
```

Or with your own build: `docker build -t pdfq:dev .`, then the same `docker run` with `pdfq:dev`.

Then either open this folder in [Bruno](https://www.usebruno.com/) and pick the `local` environment, or run it from the command line:

```sh
cd examples/bruno
npx -y @usebruno/cli@4.3.0 run --env local
# another server: --env-var baseUrl=http://localhost:3998
```

The requests run in order: health, readiness, a template compile, an upload compile (`files/main.typ`), a compile error (`422 compile_error`), then an async job (`Create job` stores `jobId`, `Job status` waits 1.5 s before polling), its PDF, and the metrics.

## Other tools

[`docs/openapi.yaml`](../../docs/openapi.yaml) (OpenAPI 3.1) imports into Postman, Insomnia or Bruno, and can generate clients:

```sh
docker run --rm -v "$PWD:/local" openapitools/openapi-generator-cli:v7.26.0 \
  generate -i /local/docs/openapi.yaml -g go -o /local/out/go
```

OpenAPI 3.1 support in openapi-generator is still marked beta. The Go client generated by this command builds after `go mod tidy` in `out/go`.
